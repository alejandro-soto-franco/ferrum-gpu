# ferrum-gpu

Pure-Rust GPU compute substrate with Python bindings.

Plan 5 expands this. For now: see [`docs`](https://github.com/alejandro-soto-franco/ferrum-gpu-planning) (planning repo, private) for design + plans, and run `make example-vector-add` after `cargo build` to exercise the CUDA path.
